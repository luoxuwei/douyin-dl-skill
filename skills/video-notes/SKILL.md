# video-notes · 视频变文档

一条流水线，五步，每步一个脚本，都在 `${CLAUDE_SKILL_DIR}/../video-dl/scripts/`：

| 步 | 脚本 | 产物 |
| --- | --- | --- |
| 1 下载 | `video-dl.mjs`（网络链接）；本地文件跳过 | `原始/<标题>.mp4` |
| 2 转写 | `transcribe.py`（见 transcribe skill） | `原始/<标题>.md .srt .txt .asr.json` |
| 3 抽帧 | `frames.mjs` | `帧/<标题>/NNNN.jpg` 和 `sheet-*.jpg` |
| 4 找画面、查链接 | 你看缩略图，ffmpeg 裁剪；子代理查链接 | `封面/*.jpg`，链接表 |
| 5 成文 | 写 `<主题>.md`，`notes-pdf.mjs` 转 PDF | `<主题>.md`，`<主题>.pdf` |

工作目录：用户指定的输出目录，没指定就在当前目录建 `视频笔记-<日期>/`。

## 步骤

### 0. 开工前问一次

用 AskUserQuestion 一次问清（用户已说明的跳过）：文档主题或标题；关注点（书单、课程要点、操作步骤、全文转写）；语言。多个视频问是合成一份还是各一份，默认合成一份、每个视频一章。

### 1. 拿到视频

- 网络链接：`node video-dl.mjs <链接> 原始/ --quality 720`。多个逐个跑。博主主页或合集链接走 video-dl 的批量流程，先列清单确认。
- 本地文件：不复制，记下路径。文件夹则处理里面所有视频。
- 记下每个视频的标题、时长（`ffmpeg -i`）、来源链接或路径。

### 2. 转写

`<venv python> transcribe.py 原始/ --outdir 原始/ --lang zh --prompt "<标题里和用户给的人名术语>"`。转完抽查 md，同音字用 Edit 改；网络视频的文案（分享文本、标题、话题标签）是最好的校正依据，用户贴了就存成 `文案.md` 参考。

### 3. 抽帧

`node frames.mjs 原始/<标题>.mp4 帧/<标题> --every 1`。五分钟视频约 300 帧、4 张缩略图；一小时课程用 `--every 5`。

### 4. 找关键画面，查链接

1. 用 Read 看每张 `sheet-*.jpg`，缩略图角上有秒数。找的目标按主题定：书封面、幻灯片、代码、图表、操作界面。转写里"这本书叫""看这张图"出现的时间是线索。
2. 定位到秒数后 Read 那一帧 `NNNN.jpg`，确认清楚，用 `ffmpeg -i 帧/x/NNNN.jpg -vf crop=W:H:X:Y 封面/<名>.jpg` 裁出来。主播头像或字幕压住的，换相邻秒数或裁掉被压部分。
3. 视频里提到的书、课程、网站，起一个子代理查链接：书名作者出版社、官方免费版或 GitHub 优先，其次出版社页和豆瓣，每个链接要访问确认标题作者对得上，有中译本一并查。多本书一次交给一个子代理。
4. 不确定的封面或链接，问用户，不猜。

### 5. 成文

按 `${CLAUDE_SKILL_DIR}/模板.md` 的结构写 `<主题>.md`：

- 开头一段来源说明：视频、日期、转写方式、图片来源。
- 一页总览：如果是书单就一张表（资源、负责哪一段、作者的用法），课程就要点列表，操作类就步骤清单。
- 每个视频一章：语音转文字（合并段落带时间戳）；提到的资料每个一节，封面图、作者出版社、链接、视频里的评价。
- 末尾总表。

图片用相对路径 `封面/x.jpg`。然后 `node notes-pdf.mjs <主题>.md --footer "<主题>"`。用 Read 看 PDF 前两页确认排版和图片都在。

### 6. 交付

告诉用户：PDF 路径和页数；每章一句话；转写里改过的错字；没找到封面或链接的项。

## 硬约束

- 转写和抽帧全在本地。视频归原作者，文档仅供个人学习，不二次分发视频文件。
- 书和资料的链接必须核对过才写；查不到就写"未找到"，不编。
- 转写文字标"AI 生成可能有错"。
- 一次别处理超过十个视频，多了让用户分批。
